# Product

FaultLane helps Unreal Engine teams turn a packaged Windows crash into a readable, symbolicated issue. The current promise is a readable test crash within ten minutes of account creation, excluding Unreal packaging time.

## Current milestone

Prove the complete Unreal Engine 5.8 crash flow with a real design partner using the installed UE 5.8.1 build. The proof must cover project setup, crash submission, symbol upload, isolated processing, and a readable issue in the dashboard.

Product work should improve this flow or remove a demonstrated blocker. Broader scale and platform work needs design-partner evidence first.

## Non-goals

- Generic observability, gameplay analytics, or session replay
- Automated crash fixes
- Console, mobile, Linux, or macOS support
- Self-hosting and broad Unreal compatibility before the late pre-launch pass
- A service per subsystem, Kubernetes, Kafka, Redis, Elasticsearch, or ClickHouse

## Future roadmap

After design-partner validation, revisit team controls, hosted operations, wider Unreal compatibility, self-hosting, and measured scale constraints. Keep future work as a short roadmap until evidence justifies executable issues and dates.
