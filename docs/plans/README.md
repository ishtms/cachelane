# Implementation plans

Create a plan for R2, R3, and R4 work. R0 and R1 work may use issue acceptance criteria unless the implementation is unusually uncertain.

A plan records:

- linked issue and measurable acceptance criteria;
- risk classification and blast radius;
- affected domains, APIs, data, security, and operations;
- implementation sequence and verification;
- rollout and rollback;
- unresolved decisions and explicit out-of-scope work.

R3 plans require human approval before implementation. R4 operations require a separate human-run procedure.
